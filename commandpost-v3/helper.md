# Download Helper

**CommandPost Helper** is an **optional** helper tool that gives Accessibility powers to **CommandPost v3**.

You should use the version of **CommandPost Helper** that matches the version of **CommandPost** you have installed from the Mac App Store (or TestFlight).

You can [download the latest version on GitHub](https://github.com/CommandPost/CommandPost/releases).

---

## What does it do?

Applications on the Mac App Store aren't allowed Accessibility Permissions.

Because CommandPost needs Accessibility Permissions to control other applications, we offer an **optional** helper that is not sandboxed (although is still signed and notarised).

You don't HAVE to install the CommandPost Helper to use CommandPost - but if you don't install it, you can't use any Accessibility features.
